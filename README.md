## ✨ المميزات الرئيسية

### للعملاء 🛒
- 🛍️ **سلة تسوق ذكية**: حساب الكميات والخصومات والتحقق من الأسعار من الخادم (Firestore).
- 🎁 **عروض وهدايا ترويجية**: نظام هدايا مجانية تلقائي عند الوصول للحد الأدنى للإنفاق.
- ❤️ **قائمة الأمنيات (Wishlist)**: حفظ ومزامنة المنتجات المفضلة.
- 🔍 **بحث وفلترة فورية**: فلترة دقيقة حسب القسم ونوع البشرة والخصومات.
- 📦 **إدارة وتتبع الطلبات**: استعراض حالات الطلب من الحساب الشخصي (Pending, Processing, Shipped, Delivered, Cancelled).
- ⭐ **نظام التقييم التلقائي**: نافذة تفاعلية ذكية تطلب مراجعة العميل فور استلام الطلب مع مزامنة سحابية لحظية.
- 💬 **محادثة مباشرة مع الدعم (Live Chat)**: تواصل فوري مع فريق خدمة العملاء من داخل المتجر.
- 🌐 **دعم كامل للغتين (i18n)**: واجهة ثنائية اللغة (العربية والانجليزية) مع دعم كامل لاتجاه النصوص (RTL/LTR).
- 🌙 **الوضع الليلي (Dark Mode)**: تصميم متكيف ومريح للعين مع Tailwind CSS.

### للإدارة والمديرين 🔧
- 🛡️ **حماية حقيقية للوحة التحكم**: التحقق من صلاحيات المدير عبر Firebase Auth ومستندات Firestore (`users/{uid}`) مع حجب واجهة اللوحة تلقائياً حتى اكتمال التحقق.
- 📊 **إحصائيات ولوحة مؤشرات متقدمة**: إجمالي المبيعات، الطلبات، العملاء، والمنتجات.
- 📦 **إدارة المنتجات (Catalog CMS)**: إضافة وتعديل وحذف المنتجات والتحكم في الأسعار والمخزون ونسب الخصم.
- 🏷️ **إدارة الأقسام والبانرات**: التحكم في البانرات الإعلانية الترويجية وأقسام المتجر باللغتين.
- 🛍️ **إدارة ومعالجة الطلبات**: تحديث حالات الطلبات لحظياً وتدوين الملاحظات الإدارية.
- 👥 **إدارة العملاء والصلاحيات**: استعراض سجلات العملاء، حظر الحسابات المسيئة مباشرة في Firestore، وتعيين الصلاحيات المخصصة.
- 💬 **صندوق محادثات الدعم (Inbox Hub)**: استقبال استفسارات العملاء والرد عليها لحظياً.
- ⚙️ **إعدادات المتجر الفورية**: تعديل هوية المتجر، وسائل التواصل، ونظام الهدايا بدون إعادة نشر الكود.

## 🔒 البنية الأمنية (Security Architecture)

تم إجراء تدقيق برمجي وأمني شامل (Security Code Audit) للمشروع وسد كافة الثغرات:
1. **الوقاية التامة من ثغرات الحقن (Stored XSS)**:
   - تمرير كافة البيانات القادمة من المستخدمين وقاعدة البيانات عبر دوال تعقيم صارمة (`escapeHtml`) لمعالجة الرموز الخاصة (`<`, `>`, `&`, `"`, `'`) في نصوص وخصائص HTML Attributes.
   - التحقق الأمني من الروابط (`safeUrl`) وحظر أي روابط خبيثة تبدأ بـ `javascript:` أو `data:text/html`.
2. **التحقق من الأسعار والطلبات من الخادم**:
   - قبل اعتماد الطلب، يجلب نظام الدفع أسعار المنتجات المعتمدة مباشرة من مجموعة `products` في Firestore ويعيد حساب الإجمالي لمنع التلاعب في أسعار `localStorage`.
   - تسجيل الطلبات بـ `userId` مطابق لمعرف Firebase Auth الفعلي (`auth.currentUser.uid`).
3. **التحقق من حظر المستخدمين (User Blocking Enforcement)**:
   - فحص حالة الحساب مباشرة من مستند Firestore (`users/{uid}`) والتأكد من أن `isBlocked !== true` و `status !== 'Blocked'` قبل السماح بإتمام أي طلب.
4. **حماية لوحة الأدمن (Admin RBAC)**:
   - حجب واجهة لوحة التحكم افتراضياً مع شاشة فحص الصلاحيات.
   - التحقق السحابي عبر `onAuthStateChanged` و Firestore وعدم الوثوق مطلقاً في أي كائن محلي بـ `localStorage`.
   - إعادة التوجيه الفوري لغير المصرح لهم عبر `window.location.replace('login.html')`.
5. **قواعد أمان محصنة في `firestore.rules`**:
   - منع المستخدمين العاديين من تعديل الحقول المحمية (`role`, `isAdmin`, `isBlocked`, `status`, `permissions`).
   - حصر استعلامات الطلبات الخاصة بكل مستخدم على معرفه (`userId == request.auth.uid`).

## 🚀 تشغيل ونشر المشروع

### 1. التشغيل المحلي (Local Development)
يفضل تشغيل المشروع عبر خادم ويب محلي (مثل Live Server في VS Code أو سيرفر بايثون) لضمان عمل Firebase Auth وخدمات Google بشكل صحيح:
```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx serve .
```

### 2. النشر على Firebase Hosting
تم ضبط إعدادات الكاش وقواعد النشر في `firebase.json` لإرسال التعديلات للعملاء فوراً:
```bash
firebase deploy --only hosting,firestore:rules
```
